# Заміна зображень

Ця папка призначена для фінальних локальних фотографій з портфоліо.

Зараз у HTML використано якісні едиторіальні тимчасові зображення з Unsplash, щоб сайт виглядав завершеним, поки ви готуєте реальні роботи фотографа. Щоб замінити їх пізніше:

1. Додайте фінальні зображення в цю папку `images/`.
2. Оновіть атрибути `src` і `data-lightbox-src` у HTML-сторінках.
3. Тримайте великі hero-зображення шириною близько 2200 px, а зображення для галереї — близько 1400 px: так сайт виглядатиме чітко, але залишиться легким.
